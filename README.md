# Dino Den

A dinosaur app for kids. It's a single web page with no build step and no dependencies.

## Features

- **Meet:** 16 dinosaurs, each with:
  - a roar sound and read-aloud facts
  - a drawing to scale next to a child
  - a timeline of when it lived
- **Dig:** brush away the sand to uncover a hidden fossil.
- **Quiz:** 5 questions with stars and a saved best score.
- **Languages:** English, 中文 (Mandarin, with pinyin) and Svenska.
- **Themes:** Rainbow and Dark green.

## Run it

Open `index.html` in any browser.

## Host it with GitHub Pages

Go to **Settings → Pages**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.
